# 四關四題正式賽制

更新日期：2026-09-30

本文件描述目前正式地圖的玩法。架構與資料流見 [`PROJECT_ARCHITECTURE.md`](PROJECT_ARCHITECTURE.md)；數值的最終來源是 `shared/game-config.js` 與 `data/maps/wedding-final-showdown.json`。

## 正式流程

- 正式 16 題、4 關，每關四題，五隊、單局決勝。
- 開賽倒數 3 秒後自動連點 8 秒，再進入 `awaiting_question`。
- 主持按「開始第 1 題」；每題作答 10 秒後進入 `reveal`，保留完整統計。
- 前三題結果後按「下一題」；第四題結果後按「顯示本關結算」。
- `summary` 保留至主持按「開始下一關」；第四關後按「開始最後衝刺」。
- 最後衝刺 10 秒，自動完賽；5 秒後進入四項最終頒獎。

自動計時只涵蓋倒數、連點、題目作答與最後衝刺：3 + 4×8 + 16×10 + 10 = 205 秒。
每題之間及每關之間由主持控制，因此總時間取決於主持停留時間，另加暫停與頒獎轉場。

## 連點與折返跑道

正式模式採草地折返跑道。單程預設 1500 距離單位，來回 3000 為一圈。畫面左右位置只代表折返動畫，不代表名次；排名與完賽判定使用伺服器累積距離。

連點階段不會因任何隊伍到達畫面端點而提前完賽。每位玩家第 20、40、60……次被接受的點擊為 2 倍爆擊。最後衝刺預設再套用 2 倍點擊倍率。

## 答題與階段獎勵

每題以開始時的隊伍總人數為分母：`correctRate = correctCount / totalCount`。
未作答包含在分母，嚴格 `correctRate > 0.5` 才算答對；剛好 50% 不算答對。
空隊伍為 0%，不算答對。個人未作答不增加 wrongCount。最高票選項只供相容顯示，不參與判定。

每關四題結束後一次發獎：

| 本關答對 | 前進格數 | 預設距離 |
| ---: | ---: | ---: |
| 0 | 0 | 0 |
| 1 | 1 | 1500 |
| 2 | 2 | 3000 |
| 3 | 4 | 6000 |
| 4 | 6 | 9000 |

逐題揭曉只展示結果，不立即改變位置；階段結算只執行一次。重整、重連與狀態重送不得重複發放獎勵。

## 題目規則

- 正式題表位於 `data/maps/wedding-final-showdown.json`。
- 題數必須是每階段題數的倍數，正式地圖固定 16 題、4×4；自訂地圖為 4 的倍數。
- 每個 `quizId` 必須存在且不得重複。
- 每題作答秒數限制在 1–60 秒。
- 題目內容位於 `data/quizzes/*.json`，新人私事題必須由本人確認答案。

不符合上述條件時，`startRound()` 在鎖定玩家前拒絕開賽。

## 主持控制

- 只有 `/control/` 與 `/admin/` 可控制賽事。
- 每題必須由合法 Control／Admin 使用正式推進事件開始；force quiz 不可繞過。
- 作答、揭曉或結算期間不能插入另一題。
- 暫停會凍結計時，且拒絕進題、結算、下一關及衝刺操作。
- 重置會取消所有待執行流程、清除玩家、統計、操作帳本與舊題目。
- 音效只在投影頁播放，工作人員需先點擊啟用音效。
