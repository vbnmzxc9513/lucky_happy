# 六關三題婚禮賽制

更新日期：2026-09-14。此規格取代舊版十題與九分鐘衝刺機制。

## 正式流程

- 開賽倒數 3 秒。
- 六個關卡，每關：連點 8 秒、開場 3 秒、三次「作答 10 秒 + 答案揭曉 2 秒」、隊伍結算 8 秒。
- 完成全部 18 題及六次結算後，最後衝刺 10 秒，以累積距離最多的隊伍獲勝。位置相同沿用平手規則。
- 預估到完賽為 343 秒（5:43）；再 5 秒切換最終頒獎。報到、規則、主持暫停與人工揭獎時間不包含在內。
- 30、75、150、180 人的排程相同，不受手速影響；主持提前進關會縮短時間，暫停會延長實際時間。

## 計分

正式模式採草地折返跑道，單程 1500 單位、來回一圈 3000 單位。圈數只由累積距離換算，折返端點不會結束比賽。畫面左右位置不是名次；距離插值後才換算折返位置。舊模式保留單程跑道。

每題採用隊內最多票的選項。最多票同票或全員未作答，該隊本題不計答對。沿用現有多數決邏輯，不改成個人正確率。

| 本關答對 | 獎勵 |
|---|---|
| 0 題 | 0 格，不倒退、不因答錯暈眩 |
| 1 題 | 1 格 |
| 2 題 | 2 格 |
| 3 題 | 4 格，包含全對額外 1 格 |

目前一格為 1500 遊戲距離單位。只在三題結束後一次發放，重複同步或重新整理不會再次發放。
賽道道具仍沿用原有規則；不作答不會增加個人錯題王的錯題數。

## 出題與主持

- 出題介面為 `/admin/#tab-quiz`。題目順序每三題一組，作答秒數可逐題設定。
- 時間估算由前後端共用 `shared/stage-plan.js` 計算；調整賽道距離不會改變分關時間。
- 題表必須是三的倍數、題目存在且不重複，否則不能開賽。保存時不會默默刪除超出的題目。
- 新增八題 `party_001` 至 `party_008` 為一般婚禮暖場備用題，可替換；既有新人私事題的答案仍需本人確認。
- 主持控制台只能在連點期間提前進入下一組三題，不能在答題或結算中插入其他題目。
- 暫停會凍結分關、作答、結算及衝刺計時；重置會取消所有待執行流程。
- 三題成績星星與獎勵馬匹動畫同時呈現五隊，音效只在投影頁播放，需先按啟用音效。

## 驗證

`npm test` 包含六關回歸、重複操作、150 人模擬計分、全對／不作答／混合答案／極快位置、各階段暫停重置、重連答案鎖及出題時長試算。

完整 Socket 負載測試：

```powershell
node scripts/stress-wedding-game.js --url http://127.0.0.1:3000 --clients 150 --reconnectClients 15 --reconnectAtQuiz 5 --maxSeconds 480
```

此指令會重置及操作賽事，僅供空站彩排。報告包含 18 題結果、6 次隊伍結算、6 段連點時間、重連及效能。

`scripts/test-stage-browser.js` 是可選的 Playwright 畫面驗證，需要可用的 Chrome 與 Playwright（可由 `PLAYWRIGHT_MODULE` 指定安裝位置）。它觀看進行中的賽事，不會按開始或重置；截圖保存在 `reports/stages/`。

本機通過不代表已驗證 DigitalOcean、宴會廳網路、真實手機音訊或投影設備，正式場地仍需彩排。
